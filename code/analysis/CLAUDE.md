# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this directory is

This is not a codebase and not a git repository. It is a reference-document holding folder inside the execution phase (`ejecucion/`) of a funded research project at Universidad de Cuenca (UCuenca), Ecuador — see the parent `CLAUDE.md` at `../../CLAUDE.md` for full project context (title, PI, budget, schedule, team).

The only contents are PDFs in `info/`:

- `Formulario 2_Propuesta de proyecto_v2.pdf` — the submitted project proposal.
- `1_reporte tecnico_30_01_2025_revIMA.pdf` — a technical report.
- `1-s2.0-S0360544220314857-main.pdf` — an external reference paper (journal article).

There is no build, lint, or test tooling here, and no source code to navigate — there is nothing to run or compile.

## Where the real work lives

The project's actual code, data, and public-facing documentation live in a separate git repository, `renon-azuay/` (sibling of `convocatoria_XXII/ejecucion/`), which tracks `origin/main` on GitHub. Administrative/legal documents and the Scrumban project-management files live under `convocatoria_XXII/legal/` and `convocatoria_XXII/gestion/`, documented in the parent `CLAUDE.md`.
